# Contributing to pair-project

Welcome! This repository is for learning GitHub collaboration with real contributions.

## Getting started

1. Create an issue describing the improvement or bug fix.
2. Create a new branch from `main` (for example, `docs/improve-guide`).
3. Make a meaningful change and check that it works.
4. Commit your change with a clear message.
5. Open a pull request against `main`, explain what changed, and request a review.
6. Address feedback before merging.

## Working as a pair

If two people genuinely create a commit together, add a `Co-authored-by: Name <verified-email@example.com>` trailer using the actual co-author's verified GitHub email. Never add a co-author who did not participate. Both contributors can review and discuss the pull request.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Links or code examples were checked.
- [ ] The description explains the change and how it was tested.
- [ ] Any credited co-authors actually contributed.
